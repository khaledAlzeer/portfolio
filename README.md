## ✨ Features

- **Animated hero section** with a code-terminal visual and typewriter role text
- **Scroll-reveal animations** across all sections
- **Tabbed skills grid** — Languages / Frameworks & Data / Tools
- **Project cards** linking directly to GitHub repositories
- **Certificates section** with completed and in-progress states
- **Contact grid** with direct links to Email, LinkedIn, GitHub, Codeforces, and WhatsApp
- **Fully responsive** — mobile slide-in drawer navigation
- **Downloadable CV** in a matching, print-ready design

## 🚀 Running Locally

No dependencies needed — it's static HTML/CSS/JS.

```bash
git clone https://github.com/khaledAlzeer/portfolio.git
cd portfolio
```

Then just open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.
